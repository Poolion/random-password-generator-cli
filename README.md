# Random Password Generator (CLI)

A simple command-line tool to generate a random password with specified length and character types.

## Installation

Download the latest version of the tool from the repository or clone the repository to your local machine.
```
git clone https://github.com/Poolion/random-password-generator-cli
```

## Usage

To use the tool, run the following command in your terminal:
```
python random_password_generator.py
```

After running the command, you will be prompted to enter the length of your password and specify the types of characters to include (uppercase, lowercase, digits, and special characters).

**Example: **
```
$ python random_password_generator.py
Enter password length: 12
Include uppercase letters? (y/n): y
Include lowercase letters? (y/n): y
Include digits? (y/n): y
Include special characters? (y/n): n
Generated password: R7gJm6nL2fA0
```
