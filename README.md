# random-password-generator-cli

A small Python CLI that generates a random password with configurable length and character sets.

## Usage

```bash
python random_password_generator.py --length 16
```

## Install

```bash
git clone https://github.com/Poolion/random-password-generator-cli.git
cd random-password-generator-cli
python random_password_generator.py
```
